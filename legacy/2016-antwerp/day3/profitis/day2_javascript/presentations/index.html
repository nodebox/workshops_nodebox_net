Hoe linken?

3 manieren om JavaScript te linken:

  • In het element (Inline)
  • Ingebed (Embedded)
  • Extern (External)



Vergelijkbaar met CSS!

Hoe krijg ik JavaScript op mijn pagina? Net zoals CSS zijn er 3 manieren, van "makkelijker" naar "beter".

Inline JavaScript (BAD)

<a href="javascript: doSomething()">Klik mij!</a>
<a href="#" onclick="doSomething()">Mij ook!</a>
JavaScript kan mee in de HTML code worden gestoken. Ofwel via een pseudo-link (merk op dat de link niet begint met "http" maar met "javascript"). De andere manier is via een onclick attribuut op de link. Net zoals bij CSS raden we dit af. Het linkt de elementen rechtstreeks met het gedrag. Net zoals bij CSS zullen we zien dat we dit ook hier best via selectors kunnen doen.

Embedded JavaScript (OK)

<body>

  ...

  <script>
    doSomething();
  </script>
</body>
We kunnen een script-element in de pagina steken. In dit script-element typen we dan de code. Die code wordt uitgevoerd wanneer de browser de script-tag tegenkomt. Dit is een OK methode, zeker als de JavaScript-code maar op één pagina gebruikt zal worden. We hebben dit al gebruikt in het single socks project, waar we een beetje JavaScript hadden geschreven om de gallerij en de flip-cards in gang te zetten.

Externe JavaScript (Goed!)



  ...

  <script src="myscript.js"></script>
</body>
</html>
Bij de laatste methode maken we, net zoals bij CSS, een apart bestand dat alle externe code bevat. We linken dan naar dit bestand vanuit onze HTML pagina. Dit is nuttig wanneer de code in het bestand op meerdere plaatsen in onze site moet gebruikt worden. Bijvoorbeeld code voor een navigatie-menu dat op alle pagina's in onze site wordt gebruikt steken we in een apart document. Net zoals bij CSS is deze methode ook interessant qua snelheid: de browser moet het bestand namelijk maar één keer downloaden en kan het voor de volgende pagina's herbruiken. Merk op dat we het script helemaal onderaan de pagina zetten.

JavaScript is een programmeertaal

Over HTML en CSS kunnen we zeggen dat het *opmaaktalen* zijn. JavaScript is een echte programmeertaal. We kunnen dus heel wat doen. Het zorgt er ook voor dat het de moeilijkste is van de drie.

JavaScript ≠ Java

Misschien heb je al wel eens van "Java" gehoord. Ondanks de naam zijn JavaScript en Java twee verschillende programmeertalen.

Overzicht

We willen nu een snel overzicht geven van de standaard mogelijkheden van een programmeertaal. Deze zullen in het begin verwarrend zijn; geen paniek. We gaan ze allemaal één voor één gebruiken in de oefening achteraf.

Developer Tools

Het makkelijkste is om mee te volgen. Open de pagina excercises\javascript\index.html in Chrome. Dan druk je op alt-command-j om de developer tools console open te doen. Hieronder gaan we code typen. Probeer al eens 5 + 3 te typen, en dan ENTER.

Operatoren

(3 * 2) + 4;
Operatoren ken je uit de wiskunde. Het zijn dingen zoals +, -, maal en gedeeld door, die we gebruiken om berekeningen mee te doen. Hier vermenigvuldigen 3 en 2, en tellen we daar 4 bij op. Probeer deze soms eens te typen in de developer tools console.

Variabelen

                var favorieteKleur = 'rood';
We beginnen met variabelen. Variabelen laten ons toe om een waarde op te slaan onder een bepaalde naam, zodat we er achteraf naar kunnen verwijzen. Probeer deze regel te typen. Merk op dat er geen resultaat komt. Het resultaat wordt namelijk opgeslagen in een variabele, niet teruggeven. Typ daaronder favorieteKleur en druk op ENTER. Nu zie je de waarde van de variabele. Probeer een andere waarde op te slaan, bv. "var favorieteKleur = 'blauw' ". Typ daarna nog een favorieteKleur + ENTER.

Variabelen

var favorieteKleur = 'rood';

hoofding.style.color = favorieteKleur;

We kunnen dit gebruiken als we een bepaalde waarde op meerdere plaatsen nodig hebben. Als we later een andere favoriete kleur hebben, dan moeten we die maar op één plaats veranderen.

Operatoren + Variabelen

var eenheidsPrijs = 5;
var aantal = 3;
var vervoerskosten = 6;

var totaal = (aantal * eenheidsPrijs) + vervoerskosten;
Operatoren zijn uiteraard handig in combinatie met variabelen. In dit voorbeeld verkopen we bloemen. Elke bloem kost hetzelfde: dit slaan we op in de eenheidsprijs. We houden ook het aantal verkochte bloemen bij, en de vervoerskosten. In dit geval hebben we dus een prijs van 21: 3 bloemen aan 5 euro per stuk + 6 euro vervoerskosten. Probeer dit over te typen. Als je daarna totaal + ENTER typt, zou je de waarde 21 moeten terugkrijgen.

Strings (Tekst)

var voornaam = 'Linus';
JavaScript kent ook "strings". Hier is geen goed Nederlands woord voor, dus ik gebruik meestal "stukje tekst" als synoniem. Een string is een reeks van tekens, of letters, achter elkaar. Strings gebruiken we als we met tekst willen werken. Een string staat altijd tussen aanhalingstekens. Zo kan JavaScript het onderscheid maken tussen een string ("Linus") en een variabele (voornaam).

Strings (Tekst)

var voornaam = 'Linus';

var begroeting = 'Hallo ' + voornaam + '!';

alert(begroeting);

Resultaat

voornaam'Linus'
begroeting'Hallo Linus!'
Strings kan je ook aan elkaar plakken via de "+" operator. Zo kan je verschillende stukjes tekst combineren. In dit geval combineren we drie stukjes: het woord "Hallo", de waarde van de variabele "voornaam", en het uitroepteken. In het geheugen van de browser zijn nu twee variabelen opgeslagen. De variabele voornaam is gelijk aan Linus. De variabele begroeting is gelijk aan "Hallo Linus!" Probeer dit eens. Verander "Linus" door je eigen voornaam. Probeer dan "alert(begroeting)".

Commentaar

// Deze lijn wordt niet uitgevoerd.

// Commentaar wordt vaak gebruikt om dingen te verduidelijken.
Vaak is het handig om in JavaScript uitleg te geven over wat je aan het doen bent. Dit is handig als jij iets maakt voor andere mensen, of andere mensen voor jou. Maar dikwijls is commentaar ook voor jezelf, als je een script na een aantal maanden terug opendoet. Je gebruikt twee dubbele schuine strepen aan het begin van een lijn commentaar. Commentaar wordt door de browser volledig genegeerd. Probeer de tekst hamburger eerst gewoon in de console te typen. Merk op dat de browser een fout geeft: Uncaught ReferenceError. Zet er nu twee schuine strepen voor. De browser negeert nu je invoer en zal gewoon doorgaan.

Code in Commentaar

Commentaar wordt ook gebruikt om stukjes code tijdelijk "uit te schakelen". Je kan ze zo laten staan, zonder dat ze worden uitgevoerd. In Brackets en andere editors kan je een heel blok code in commentaar zetten via een sneltoets (Command-/).

console.log

console.log('mijn bericht');
Een andere handige feature van JavaScript is de console. We kunnen in de developer console gaan zien of er iets misloopt (er komt dan een rode foutboodschap). We kunnen de console ook gebruiken om er berichten in te schrijven. Dit is handig wanneer we willen verifiëren dat het verwachte resultaat ook daadwerkelijk klopt. Probeer nu console.log('hallo') en console.log(5 + 3).

Lijsten (arrays)

var winnendeLottoNummers = [3, 10, 14, 17, 20, 28];

var kleuren = ['rood', 'groen', 'blauw', 'geel'];
JavaScript heeft ook lijsten, in het engels "arrays" genoemd. In een lijst kan je zowel nummers als strings bewaren (en ook nog andere dingen, die zien we later). Lijsten zijn een enorm krachtig concept, en de basis van bijna elk programma. Als je een computerspelletje zou maken zou je bijvoorbeeld een lijst van monsters op het scherm kunnen bijhouden. Als je een interactief boek maakt kan je een lijst maken van de plaatsen waarop je kan klikken. Of je kan een lijst bijhouden van de filmpjes die je na elkaar wil afspelen, een "playlist". In JavaScript zijn er heel wat mogelijkheden om de elementen van een lijst te behandelen, elementen bij in een lijst te zetten en eruit te halen, een lijst te sorteren, en nog veel meer.

Functies

function optellen(a, b) {
    return a + b;
}

var resultaat = optellen(5, 3);
JavaScript heeft ook functies. Dit zijn blokjes met code met een naam die we kunnen uitvoeren. Dit is handig als we een stukje code op meerdere plaatsen willen gebruiken. Hier maken we onze eigen functie "optellen", die we achteraf kunnen aanroepen met bepaalde waarden. De "a" en "b" worden dan vervangen door de waarden 5 en 3, in dit geval. Dit geeft het resultaat 8, die we bewaren in de variabele resultaat.

Condities

if (jouwVerjaardag) {
    alert('Gelukkige verjaardag!');
}
JavaScript heeft ook condities. Die zorgen dat we bepaalde stukken code enkel uitvoeren als we aan een bepaalde voorwaarde voldoen. In dit geval houden we in de variabele "jouwVerjaardag" bij of het vandaag jouw verjaardag is. Als dat zo is (en *enkel* als dat zo is), tonen we de boodschap "Gelukkige verjaardag!" op het scherm (de ingebouwde alert-functie toont een kadertje op onze pagina.)

Objecten

var president = {
    voornaam: 'Barack',
    achternaam: 'Obama',
    leeftijd: 54
}

alert(president.achternaam); // 'Obama'
JavaScript kent ook objecten. Dit is een filosofie van programmeren die lijkt op objecten in de echte wereld. In dit geval heeft een president een voornaam, achternaam en leeftijd. Een object kan vanalles zijn: als je een web-winkel kan een product een object zijn, maar ook een klant is een object, en het virtuele winkelkarretje is een object. Een object heeft eigenschappen (engels: properties). Een eigenschap is zoals een variabele die vastplakt aan een object. Je kan aan de eigenschap van een object aan via het puntje. In dit geval vragen we de achternaam van de president door te schrijven "president.achternaam". Probeer dit eens. Maak jezelf president, en typ je eigen voornaam, achternaam en leeftijd.

Objecten: functies

// Voeg het product toe aan het winkelkarretje.
shoppingCart.add(product);

// Zeg het auto-object dat het moet beginnen rijden.
car.drive();

if (jouwVerjaardag) {
    // Speel het geluid af als het jouw verjaardag is.
    song.play();
}

// De console is ook een object. "log" is een functie op dit object.
console.log(42);
Aan een object kunnen we ook functies hangen. Zo kunnen we een shoppingCart-object hebben, waar we een product aan kunnen toevoegen. Of als we een virtueel autootje hebben, kunnen we een functie "drive" maken die het autootje laat rijden. We kunnen dit uiteraard ook combineren met condities: als het jouw verjaardag is, spelen we het "happy birthday" liedje af. De browser heeft een aantal ingebouwde objecten, zoals de console. "log" is een functie op dit object. Probeer al deze voorbeeldjes eens uit!

JavaScript op de pagina

De DOM

(Document Object Model)

JavaScript zit in alle browsers en het kan interreageren met elementen op de pagina, en ze ook veranderen. Maar hoe doet het dat? JavaScript werkt met de pagina door iets dat het Document Object Model heet, of de DOM. Het is een boomstructuur aan elementen op de pagina. Je kan het het beste voorstellen als de boomstructuur die we in de inspector tools hebben gezien. Elk element (tag) is ook een object in JavaScript waar je aan kan. Die objecten hebben ook eigenschappen en functies waarmee de inhoud ervan kunnen aanpassen. Je kan de DOM zien als de hendels, of haken die je kan gebruiken om delen van de pagina te pakken en aan te passen. Dat is net zoals CSS! We gebruiken een selector om aan een element te komen, dan kunnen we de eigenschappen veranderen, of functies op dat object uitvoeren.

JavaScript op de pagina

HTML

<h1>Naam: onbekend</h1>

JavaScript

// Gebruik de querySelector method.
// We gebruiken dezelfde soort selector als in CSS.
var naam = document.querySelector('#naam');

// Verander de inhoud via de eigenschap innerHTML.
naam.innerHTML = 'Linus';
Hoe geraak ik dan aan elementen op de pagina? Er zijn verschillende manieren, maar wij gaan er maar één zien: querySelector. Het is een functie die aan het document object hangt, en die je op dezelfde manier gebruikt als in CSS. Het enige verschil is dat je hier ook aanhalingstekens moet gebruiken, omdat het om een string gaat.

Het is belangrijk te begrijpen *wanneer* de JavaScript-code wordt uitgevoerd. De eerste en belangrijkste regel is: de code wordt uitgevoerd wanneer de browser je script-tag tegenkomt. Dit heeft belangrijke gevolgen voor hoe je de pagina opbouwt. Hier is een voorbeeld: we willen reageren als er op een knop wordt geklikt. Echter, het script staat bovenaan de pagina, en wordt uitgevoerd op het moment dat de browser het script tegenkomt.

Interactiviteit

Events

Events gebeuren wanneer er een actie plaatsvindt op de pagina.

Om de pagina interactief te maken, moeten we iets doen met "events" (gebeurtenissen). Events gebeuren wanneer er een actie plaatsvindt op de pagina.

Events

  • click
  • mouseover
  • mouseout
  • mousedown
  • mouseup
  • mousemove
  • focus
  • change
  • blur
  • load
Dit zijn een aantal veelvoorkomende gebeurtenissen op een pagina: als er op een element wordt geklikt, als de muis erover gaat, of weggaat van een element. Als de muisknop naar beneden is gegaan, of net naar boven is gegaan; als de muis is bewogen. Focus, change en blur zijn events op tekstvelden. Focus is als je in een tekstveld gaat staan. Change is als je het aanpast, blur is als je het veld terug verlaat. Ze worden bijvoorbeeld gebruikt voor validatie. Load is een event dat op de pagina staat en dat gebeurd wanneer de volledige pagina, inclusief alle beelden, is geladen. Er zijn er nog meer, maar dit zijn de meest voorkomende.

Events

Je kan een listener functie aan een event op een element hangen.

Gebruik addEventListener op het element.

// Selecteer eerst het element, zoals voorheen.
var hoofding = document.querySelector('h1');

// Gebruik addEventListener met de naam van het event en een functie.
hoofding.addEventListener('click', doSomething);
Om te reageren op events hangen we een listener, een functie, aan een gebeurtenis op een specifiek element. Als het event gebeurd, wordt de listener functie aangeroepen.

Events

OK, ik kan een listener vasthangen aan een element. Wat kan ik er mee doen?

Alles!

Eens we weten hoe we een element hebben, kunnen we heel wat doen. We kunnen de stijl veranderen. Om te reageren op events hangen we een listener, een functie, aan een gebeurtenis op een specifiek element. Als het event gebeurd, wordt de listener functie aangeroepen.

Events

Stijl aanpassen

// Maak eerst een functie die de kleur van het element aanpast.
function changeColor() {
    this.style.color = randomColor();
}

// Selecteer het element.
var hoofding = document.querySelector('h1');

// Gebruik addEventListener met onze functie.
hoofding.addEventListener('mousemove', changeColor);
We kunnen de stijl veranderen. Om dit te proberen, herlaad eerst de pagina. Dat zorgt ervoor dat de vorige event listener niet meer op de H1 hangt. Anders zouden er twee events gebeuren. NOOT: om meerdere lijnen in de console te typen, zoals bij de functie, moet je SHIFT+ENTER gebruiken. Merk op dat style.color gelijk is aan de CSS color eigenschap. Dat komt omdat je aan alle dingen die je in CSS kan zetten, je ook in JavaScript kan. Heb je trouwens het woord "this" gezien? Dit verwijst naar het huidige element. Als we op een element klikken, zet de browser het woord "this" naar hetgene waar we net op geklikt hebben.

Events

Stijl aanpassen: classes

// Selecteer het element.
var hoofding = document.querySelector('h1');

// Gebruik classList.add om een klasse toe te voegen.
hoofding.classList.add('blinky');

// Gebruik classList.remove om een klasse te verwijderen.
hoofding.classList.remove('blinky');
Als we te veel van die stijl-dingen opgeven, gaan we het gedrag van de pagina beginnen mengen met de vormgeving van de pagina. Het is handiger van dit in CSS te doen. We kunnen een class aan een element hangen of verwijderen. Zo kunnen we de stijl in CSS later aanpassen. In dit geval gebruiken we CSS animations (die we nog niet gezien hebben) om een element te laten animeren.
