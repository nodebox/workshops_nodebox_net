ComicMeme:

“Spot the bullshit”
A meme done in OpenType. Comic Sans is a meme in the designers’ world: it should be categorically avoided. But what if the designer is just bullshitting about his own work?

ComicMeme is an Opentype font. Mainly the characters are in Times New Roman. When a designer writes about his work the font detects if he/she is bullshitting. Buzzwords are changed to Comic Sans.

This is done with OpenType ligature features. Currently the features only work in Adobe applications that can make use of the ligatures in an OpenType font. Mikko: try out writing about your project. Others: thank Frederik for the great help he’s been to us!

Here’s the font: ComicMeme_02a.otf
