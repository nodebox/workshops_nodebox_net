Here’s a list of improvements for the wiki:

A guestbook

Provide visitors with a place to vent comments. Just name and text. Fill-in screen can appear at the top, with small textarea that expands once you click on it. No HTML allowed. Accept linebreaks, but squeeze them so you can’t add more than one.

A general plugin architecture

But really easy: We have a basic list of actions (edit, permissions, passwords, etc.), and if you provide an action that is not on the list, check if there is a plugin named that way in the plugins directory. A plugin can either be one file (guestbook.php) or a folder containing an index.php . Call a specific function on the file, such as “do”. Great name, that

Another option is to do it like django flatpagehandler: right before a 404 is shown, try to see if a plugin with that name is available.
