Here are two clumsily named “applications”, made with NodeBox to test my coding skills, that could be used in designing pixel fonts:

pixel font creator - pixelfontcreator

The code is very messy, full of notes in Finnish I put there to help me understand the python code better.

O, d, A?

pixel character tester - pixelcharactertester

Refined version of the one above. While the the other one could help you in designing whole fonts or words, this one could be used more accurate work: in designing single glyphs or letters. The overlayed text helps you to think how glyphs are formed in other fonts.

There’s still a pretty irritating problem with this one, though. I couldn’t figure out how to differentiate the pixel grid creation from other commands in the code. So, when eg. the sliders are touched, NodeBox runs the code and the pixel grid is generated. Whether you want it or not.
